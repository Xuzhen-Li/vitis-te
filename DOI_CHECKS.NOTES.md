# DOI_CHECKS year convention

The `year` column is the **print-volume year** when the v1 row already used that convention, and the **Crossref issued year** for rows added in an earlier check (see each row’s `note`).

These two can differ by one year. An erratum (e15e500c) corrected four v1 cases; the example catalog rows are **28 and 60**, not 63:

- 10.1038/nrg3374 — 2013 print / issued 2012
- 10.1093/nar/gkv1272 — 2016 / 2015
- 10.1104/pp.17.01310 — 2018 / 2017
- 10.1093/bioinformatics/bty745 — 2019 / 2018

That difference is not treated as a title error.
