# 《转座子从发现到实践，以葡萄为例》

This folder holds a Chinese book on transposable elements, from their discovery to practical analysis, with grapevine (*Vitis*) as the worked example. It sits beside the shorter catalogue in the rest of this repository and does not replace it.

本文件夹存放中文书稿《转座子从发现到实践，以葡萄为例》。全书从转座子的发现史讲到注释、群体插入多态性与表型分析，并以葡萄属（*Vitis*）作为贯穿始终的范例。它与仓库其余部分的方法目录互为补充，并不取代那些页面。

完整正文见合订本 [`TE_BOOK_full.md`](TE_BOOK_full.md)。同一正文也按部分拆在 [`chapters/`](chapters/) 下。文件清单、汉字数与文献标记统计见 [`INDEX.md`](INDEX.md)。

文中凡尚未对照已打开的来源核实的说法或文献，一律标为 [待确认]。标了 [待确认] 的内容，不能当作已经核实的结论。
