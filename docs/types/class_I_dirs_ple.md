# DIRS and Penelope-like elements (PLE)

Wicker et al. 2007 ([doi:10.1038/nrg2165](https://doi.org/10.1038/nrg2165), Fig. 1) place **DIRS** as a Class I order that uses a tyrosine recombinase (YR) and has TSD length 0. **PLE** is a separate Class I order with a variable TSD. Those Fig. 1 values were not re-verified from an openly available full text in this addition and remain **[待确认]**.

Wells and Feschotte (2020, full text, [doi:10.1146/annurev-genet-040620-022145](https://doi.org/10.1146/annurev-genet-040620-022145); official Crossref title *A Field Guide to Eukaryotic Transposable Elements*) treat tyrosine-recombinase retroelements as a Class I subclass that is not mobilized by an integrase in the way canonical LTR elements are. Verbatim: “DIRS elements have inverted repeats, but these are non-identical, in contrast to true LTRs, whereas Ngaro, VIPER and TATE elements appear to have direct repeats laid out in a ‘split-repeat’ pattern.” A proposed DIRS mechanism in the same paper ends with “chromosomal integration mediated by YR.” That paper does **not** assign the split-repeat layout to DIRS, and it does not use the wording “rather than leaving a TSD.” For Penelope-like elements, Wells writes that two features “stand out: firstly, the presence of pseudo-LTRs and secondly, a GIY-YIG (amino acid motif) endonuclease domain.” That is the PLE terminal wording used here; “direct or inverse orientation” is not taken from this text.

The founding Penelope element of *Drosophila virilis* is Evgen'ev et al. 1997 ([doi:10.1073/pnas.94.1.196](https://doi.org/10.1073/pnas.94.1.196); title/abstract already in the v1 catalogue). This chapter does not invent a grape PLE count.
