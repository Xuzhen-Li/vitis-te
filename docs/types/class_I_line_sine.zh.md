# LINE 与 SINE

LINE（非 LTR 反转录转座子）是 Class I 的一个**目**。Wicker 等 2007（[doi:10.1038/nrg2165](https://doi.org/10.1038/nrg2165)，图 1；图 1 数值 **[待确认]**）在该目下列了五个**超家族**：**R2、RTE、Jockey、L1、I**。它们不是各自独立的“目”。

Wells 与 Feschotte（2020，全文，[doi:10.1146/annurev-genet-040620-022145](https://doi.org/10.1146/annurev-genet-040620-022145)）描述了常见的 LINE 机制：ORF2 带内切酶和反转录酶、靶引物反转录（TPRT），以及新拷贝常见的 5′ 截短。SINE 是非自主元件，通常来自 tRNA、7SL 或 5S RNA（Wells 与 Feschotte 2020 全文，PMC8293684：“Most SINEs are derived from Pol III-transcribed noncoding RNA such as tRNA, 7SL or 5S RNA”；Wicker 图 1 把这三者列为 SINE 超家族，[待确认]）。Wells 把 Alu 写成 7SL 来源的灵长类 SINE。

本组教学章节打开的来源中没有能支持葡萄 LINE/SINE 丰度排序或发现史的出处，这些说法不讲。论断—出处表见 [class_I_line_sine.md](class_I_line_sine.md)。
