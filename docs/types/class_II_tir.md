# TIR DNA transposons

TIR elements are Class II, **subclass 1**, order TIR (Wicker et al. 2007, abstract only, [doi:10.1038/nrg2165](https://doi.org/10.1038/nrg2165); body and Fig. 1 [待确认]). They move by cut-and-paste with terminal inverted repeats. TSD lengths below were previously taken from Wicker Fig. 1 (the structural table), not from the Wicker abstract, which does not list them; those lengths remain [待确认].

| Superfamily | TSD (Wicker 2007 Fig. 1, [待确认]) |
|---|---|
| Tc1–Mariner | TA |
| hAT | 8 bp |
| Mutator | 9–11 bp |
| Merlin | 8–9 bp |
| Transib | 5 bp |
| P | 8 bp |
| PiggyBac | TTAA |
| PIF–Harbinger | 3 bp |
| CACTA | 2–3 bp |

These ranges replace earlier unsourced “often 3 bp / ~9 bp” shortcuts. CACTA is **2–3 bp**, Mutator is **9–11 bp** (Fig. 1 values [待确认]).

A previously quoted body passage, still [待确认], derives the **hAT** name from *hobo*, *Ac–Ds* and *Tam3*, and states that plant **Stowaway** elements are “plant Mariner elements… always produce a TA TSD.”

Wells and Feschotte (2020, full text, [doi:10.1146/annurev-genet-040620-022145](https://doi.org/10.1146/annurev-genet-040620-022145)) relate PIF/Harbinger to bacterial IS5-like elements (“PIF/ Harbinger with IS5”).

McClintock (1950, title, [doi:10.1073/pnas.36.6.344](https://doi.org/10.1073/pnas.36.6.344)) is the classical maize mutable-loci paper already in the catalogue. Whether the names *Ac* and *Ds* themselves appear in the 1950 versus 1953 papers is **[待确认]** (only the 1950 title was checked in the sources opened for these chapters). Per-family naming histories for CACTA, Mutator, Tc1, PiggyBac and so on, beyond the hAT derivation in Wicker, are **[待确认]** until those original papers are opened.
