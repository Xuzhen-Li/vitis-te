# DIRS 与 Penelope 样元件（PLE）

Wicker 等 2007（[doi:10.1038/nrg2165](https://doi.org/10.1038/nrg2165)，图 1）把 **DIRS** 写成使用酪氨酸重组酶（YR）、TSD 长度为 0 的 Class I 目，把 **PLE** 写成 TSD 可变的另一 Class I 目。这些图 1 数值在本次追加中未能用可公开获取的全文复核，仍标 **[待确认]**。

Wells 与 Feschotte（2020，全文，[doi:10.1146/annurev-genet-040620-022145](https://doi.org/10.1146/annurev-genet-040620-022145)；Crossref 官方题名 *A Field Guide to Eukaryotic Transposable Elements*）把酪氨酸重组酶反转录元件写成不走整合酶、因而有别于典型 LTR 元件的 Class I 亚类。原文：“DIRS elements have inverted repeats, but these are non-identical, in contrast to true LTRs, whereas Ngaro, VIPER and TATE elements appear to have direct repeats laid out in a ‘split-repeat’ pattern。”同一段提出的 DIRS 机制以 “chromosomal integration mediated by YR” 作结。该文**没有**把 split-repeat 归给 DIRS，也没有 “rather than leaving a TSD” 这一措辞。对 Penelope 样元件，Wells 写的是两个特征 “stand out: firstly, the presence of pseudo-LTRs and secondly, a GIY-YIG (amino acid motif) endonuclease domain。” 本章只用这一末端表述；“正向或反向的 LTR 样序列” 不是从该文取出的。

*Drosophila virilis* 中命名 Penelope 的是 Evgen'ev 等 1997（[doi:10.1073/pnas.94.1.196](https://doi.org/10.1073/pnas.94.1.196)）。本章不编造葡萄 PLE 计数。论断—出处表见 [class_I_dirs_ple.md](class_I_dirs_ple.md)。
