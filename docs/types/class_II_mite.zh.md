# MITE

MITE 在本章只作为“短的、非自主、带 TIR 的 Class II 元件”的描述性名称，不是 Wicker 体系里单独的目 [待确认]。Bureau 与 Wessler 命名了 Tourist（1992，[doi:10.1105/tpc.4.10.1283](https://doi.org/10.1105/tpc.4.10.1283)）和 Stowaway（1994，[doi:10.1105/tpc.6.6.907](https://doi.org/10.1105/tpc.6.6.907)），两篇摘要目前已打开。这两篇摘要只命名了这两个家族，没有出现 MITE 或 miniature。MITE 一词最早由谁使用标为 **[待确认]**。

Zhang 等（2001，摘要，[doi:10.1073/pnas.211442198](https://doi.org/10.1073/pnas.211442198)）表明 Tourist 样 MITE 家族（mPIF）与 PIF 有相同末端和靶位点偏好，并写 “PIFa and these PIF-like elements belong to a new eukaryotic DNA transposon superfamily that is distantly related to the bacterial IS5 group。” Wicker 等 2007（[doi:10.1038/nrg2165](https://doi.org/10.1038/nrg2165)）写植物 Stowaway 是 Mariner 元件，并且 “always produce a TA TSD”。该句截至 2026-11-15 CST 未能用公开全文复核，标 **[待确认]**。

Jiang、Feschotte、Zhang 与 Wessler（2004）有时被用来综述更广的 MITE–自主元件关系。该文目前**没有**打开，仅依赖该引用的说法标为 **[待确认]**，本章不讲授。论断—出处表见 [class_II_mite.md](class_II_mite.md)。
