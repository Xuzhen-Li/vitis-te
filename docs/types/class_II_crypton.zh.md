# Crypton

Wicker 等 2007（摘要，[doi:10.1038/nrg2165](https://doi.org/10.1038/nrg2165)；正文和图 1 [待确认]）此前被用来把 Crypton 放在 Class II **亚类 1** 里、与 TIR 并列的**第二个目**。图 1 数值（仍标 [待确认]）：酪氨酸重组酶（YR），TSD 为 0，出现范围标 F（真菌）。先前引用的正文（仍标 [待确认]）：“We include the poorly known Crypton69 TEs… as a second order in subclass 1。”在该未复核正文的前提下，它不是“另行处理”的类群。

Kojima 与 Jurka（2011，摘要，[doi:10.1186/1759-8753-2-12](https://doi.org/10.1186/1759-8753-2-12)）后来在动物、真菌、卵菌和硅藻中报道了新的 Crypton 家族。DOI 10.1186/1759-8753-2-9 经核是 Herves 转座酶论文，不是这篇，不用。

末端结构标为 **[待确认]**，因为两篇已打开的出处措辞不一致：Goodwin、Butler 与 Poulter（2003，摘要，[doi:10.1099/mic.0.26529-0](https://doi.org/10.1099/mic.0.26529-0)）写 “The element contains no long repeat sequences, but is bordered by short direct repeats…”。DOI 10.1093/nar/gkg181 经核是支原体论文，不是这篇，不用；Wells 与 Feschotte（2020，全文，[doi:10.1146/annurev-genet-040620-022145](https://doi.org/10.1146/annurev-genet-040620-022145)）则把 Crypton 与带短 TIR 的元件放在一起。本章并列引用，不选定一种末端公式。论断—出处表见 [class_II_crypton.md](class_II_crypton.md)。
