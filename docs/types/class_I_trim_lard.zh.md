# TRIM 与 LARD

TRIM（terminal-repeat retrotransposons in miniature）和 LARD（large retrotransposon derivatives）是非自主的 LTR 相关元件，不是 Wicker 体系里单独的目 [待确认]。

Witte 等（2001，摘要，[doi:10.1073/pnas.241341898](https://doi.org/10.1073/pnas.241341898)；Crossref 作者为 Witte、Le、Bureau、Kumar）命名并表征了 TRIM，并写 LTR 插入位点通常有 5 bp 正向重复。Kalendar、Vicient 等（2004，摘要，[doi:10.1534/genetics.166.3.1437](https://doi.org/10.1534/genetics.166.3.1437)）把原先称为 Sukkula 的大麦元件命名并表征为 LARD。目录用语因此是“命名并表征”，不是对一个从未见过的类别的“首次发现”。

TR-GAG（2015，摘要，[doi:10.1093/gbe/evv001](https://doi.org/10.1093/gbe/evv001)）是只带一个编码 GAG 前体蛋白的开放阅读框的相关非自主类群。DOI 10.1093/gbe/evv043 经核是人类插入多态论文，不是这篇，不用。论断—出处表见 [class_I_trim_lard.md](class_I_trim_lard.md)。
