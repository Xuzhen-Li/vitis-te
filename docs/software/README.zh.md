# 转座子分析软件指南（按分析步骤）

本页把目录里的 198 个软件、数据库和流程，按分析步骤重新整理：先是整套流程覆盖了哪些步骤，再是每一步的工具，最后是可视化。每个条目给出原始论文、论文署名的实验室，以及一个客观的权威度指标。默认路线不变：EDTA，再到 TEtrimmer，再到 TEsorter，再到经过 CDS 过滤的 trusted 文库，最后软屏蔽或 panEDTA（见 [`docs/WORKFLOW.zh.md`](../WORKFLOW.zh.md)）。英文版见 [README.md](README.md)。

## 怎么读这一页

- **角色**：只有本仓库已写明的默认工具才标「本仓库默认」。其余标「备选或补充」；没有默认的步骤，各行按引用数排序，这不代表哪个工具更适合你的基因组。
- **原始论文**：题名、期刊、年份来自 OpenAlex，DOI 已用 Crossref 题名核对（171 条；其余只能在 OpenAlex 解析，已在 `catalog/SOFTWARE_AUTHORITY.tsv` 的 `doi_check` 列标明）。没有题名匹配论文的条目只给官方链接。
- **实验室**：取论文元数据里被标为通讯作者的人及其机构；没有标注通讯作者时取末位作者；另列第一作者。这是论文署名，不是对实验室的评价。
- **权威度指标**：OpenAlex 的论文被引次数（2026-11-25 取数），加下面这条固定规则得出的档位。不含主观评价。

### 档位规则

| 档位 | 规则 |
|---|---|
| 标准 | 被引 500 次及以上 |
| 成熟 | 被引 100–499 次 |
| 较新 | 被引少于 100 次，且论文发表于 2023 年或之后 |
| 小众 | 被引少于 100 次，且论文发表于 2023 年之前 |
| 无论文 | 目录中没有题名匹配的论文 |

引用数与论文所在领域无关：BEDTools、MMseqs2、IGV 这类通用工具的数字来自所有学科，不能当作它们在转座子分析中的地位。引用数也会随时间变化，逐条数据见 [`catalog/SOFTWARE_AUTHORITY.tsv`](../../catalog/SOFTWARE_AUTHORITY.tsv)。

本页共 198 条：标准 28、成熟 47、较新 42、小众 58、无论文 23。
